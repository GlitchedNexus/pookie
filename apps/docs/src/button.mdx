# Button

Buttons let people trigger an action or advance through a workflow. Pookie's
button includes accessible loading feedback, ref forwarding, three sizes, and
primary and secondary visual treatments.

```tsx
import { Button } from "@glitchednexus/pookie";
import "@glitchednexus/pookie/styles.css";

export function SaveButton() {
  return <Button>Save changes</Button>;
}
```

## Primary

Use the primary treatment once per focused area for its most important action.
